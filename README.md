# DESAFIO_DIO_SISTEMA_BANCARIO

🏦 Sistema Bancário em Python

📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema bancário simples utilizando Python, com o objetivo de praticar e desenvolver conhecimentos em lógica de programação e fundamentos da linguagem.

O sistema permite realizar operações bancárias básicas, como depósitos, saques e consulta de extrato, aplicando regras de validação para garantir o funcionamento correto das operações.

⚙️ Funcionalidades

Depósito: permite adicionar valores ao saldo da conta, aceitando apenas valores positivos.

Saque: permite retirar dinheiro da conta, respeitando o saldo disponível, o limite máximo de R$ 500 por saque e o máximo de 3 saques.

Extrato: apresenta o histórico de depósitos e saques realizados, além do saldo atual.

Sair: encerra a execução do sistema.

🧠 Conceitos de Python aplicados

Durante o desenvolvimento, foram utilizados os seguintes conceitos:

Variáveis e tipos de dados (int, float e str).

Operadores aritméticos, relacionais e lógicos.

Estruturas condicionais (if, elif e else).

Estrutura de repetição (while).

Controle de fluxo (break).

Entrada e saída de dados (input() e print()).

Conversão de tipos (float()).

Formatação de strings (f-strings).

Manipulação e concatenação de strings.

Operador condicional ternário.

🛠️ Tecnologias utilizadas

Python 3

🎯 Objetivo de aprendizagem

Este projeto faz parte da minha jornada de aprendizado em programação Python, com foco no desenvolvimento do pensamento computacional, raciocínio lógico e resolução de problemas por meio da construção de aplicações práticas.
